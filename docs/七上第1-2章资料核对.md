## 四、必须写准的教材表述（已核实）

### 1.1 正数和负数

- 像 3、50、7.8% 这样**大于 0 的数**叫作正数。
- 像 -3、-10、-0.7% 这样**在正数前加上符号「-」的数**叫作负数，符号「-」是负号。
- 0 既不是正数，也不是负数。
- 关键不是「有没有负号」，而是「它表示的量与正数表示的量意义相反」。

### 1.2.1 有理数的概念（2024 版改动最大）

- 本章表述：**可以写成分数形式的数称为有理数。**
- 依据：整数可以写成分数形式（如 3 = 3/1，-2 = -2/1），有限小数、无限循环小数也都可以写成分数形式。
- 第二章学完除法后完善：**有理数可以写成 p/q（p、q 是整数，q≠0）的形式**；反过来，形如 p/q（p、q 是整数，q≠0）的数都是有理数。
- 教材为什么改：旧表述「整数和分数统称为有理数」在数学上不够严谨（整数本身就是分数的一种写法），但对初一学生又不宜一上来就抛 p/q，所以分两步走。
- 模型里的处理：主定义用新版；把「整数和分数统称有理数」放进「说法演变」卡片，明确它是旧教材说法，不能当作严格定义。

### 1.2.2 数轴

- 规定了**原点、正方向、单位长度**的直线叫做数轴。
- 原点把数轴分成**正半轴**和**负半轴**；正半轴上的点表示正数，负半轴上的点表示负数，原点表示 0。
- 数轴上的点与有理数的对应关系：每一个有理数都可以用数轴上的一个点表示。

### 1.2.3 相反数

- 只有符号不同的两个数叫做互为相反数（如 3 与 -3）。
- 0 的相反数是 0。
- 数 a 的相反数是 -a；a 可以是正数、负数或 0。
- 多重符号化简：-(-3)=3，-|-3|=-3，-（-（-3））=-3。

### 1.2.4 绝对值

- 一般地，数轴上表示数 a 的点与**原点**的距离叫做数 a 的绝对值，记作 |a|。
- 一个正数的绝对值是它本身；一个负数的绝对值是它的相反数；0 的绝对值是 0。
- 绝对值一定是非负数：|a| ≥ 0。
- 反过来：若 |a| = a，则 a ≥ 0；若 |a| = -a，则 a ≤ 0。

### 1.2.5 有理数的大小比较

- 在水平数轴上，**左边的数小于右边的数**（正半轴在右、负半轴在左）。
- 正数大于 0，0 大于负数，正数大于负数。
- 两个负数，**绝对值大的反而小**。

### 2.1.1 有理数的加法

- 同号两数相加，取相同的符号，并把绝对值相加。
- 异号两数相加，绝对值相等时和为 0；绝对值不相等时，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值。
- 一个数同 0 相加，仍得这个数。
- 运算律：加法交换律 a+b=b+a；加法结合律 (a+b)+c=a+(b+c)。

### 2.1.2 有理数的减法

- 减去一个数，等于加上这个数的相反数：a - b = a + (-b)。
- 减法转化为加法后，统一用加法法则；符号与绝对值要同时处理。

### 2.2.1 有理数的乘法

- 两数相乘，同号得正，异号得负，并把绝对值相乘。
- 任何数同 0 相乘，都得 0。
- 乘积是 1 的两个数互为倒数；0 没有倒数。
- 运算律：乘法交换律、结合律、分配律。

### 2.2.2 有理数的除法

- 除以一个不等于 0 的数，等于乘这个数的倒数：a ÷ b = a · 1/b（b ≠ 0）。
- 两数相除，同号得正，异号得负，并把绝对值相除。
- 0 除以任何一个不等于 0 的数，都得 0；0 不能作除数。

### 2.3.1 乘方

- 求 n 个相同因数的积的运算叫做乘方，乘方的结果叫做幂。
- 在 aⁿ 中，a 叫做底数，n 叫做指数。
- 负数的奇次幂是负数，负数的偶次幂是正数；正数的任何次幂都是正数；0 的任何正整数次幂都是 0。
- 辨析重点：-2⁴ = -16，(-2)⁴ = 16；(-2)³ = -8，-2³ = -8。

### 2.3.2 科学记数法

- 把一个大于 10 的数表示成 **a × 10ⁿ** 的形式，其中 **1 ≤ a < 10**，n 是正整数。
- n 等于原数的整数位数减 1。
- 常见错：a 不在 1 到 10 之间（如 18×10⁵、0.18×10⁷）。

### 2.3.3 近似数（并入 2.3.2 最后一屏）

- 与实际接近的数叫近似数；测量得到的数一般都是近似数。
- 精确度：近似数与准确数的接近程度，可以用「精确到哪一位」表示。
- 有效数字：一个近似数，从左边第一个不是 0 的数字起，到末位数字止，所有的数字都叫做这个近似数的有效数字（2024 版教辅仍保留这一口径）。
- 例：3.14 精确到百分位（或 0.01），有 3 个有效数字；0.030 精确到千分位，有效数字是 3、0 两个。

## 五、长春中考怎么考（2022–2026，已核实的题）

| 年份 | 题号 | 题面要点 | 分值 | 对应本节 |
|---|---|---|---|---|
| 2026 | 选择 1 | -2026 的绝对值 | 3 | 1.2.4 绝对值 |
| 2026 | 选择 2 | 16 000 000 用科学记数法表示（1.6×10⁷） | 3 | 2.3.2 科学记数法 |
| 2025 | 选择 1 | 水位下降记作负数，水位上升记作什么（正负数表示相反意义的量） | 3 | 1.1 正数和负数 |
| 2023 | 选择 1 | 数轴上 a、b、c、d 四点，绝对值最小的是哪个 | 3 | 1.2.4 绝对值 + 1.2.2 数轴 |
| 2023 | 选择 2 | 38 000 000 用科学记数法表示（3.8×10⁷） | 3 | 2.3.2 科学记数法 |
| 2022 | 选择 2 | 1 800 000 用科学记数法表示（1.8×10⁶） | 3 | 2.3.2 科学记数法 |

**卷面结构（近年稳定）**：选择 8 题 × 3 分 = 24 分；填空 6 题 × 3 分 = 18 分；解答 10 题 = 78 分；全卷 120 分。

**结论（写进课堂落点）**

1. **第 1 题基本是「有理数概念」的 3 分题**：2023 考数轴上的绝对值最小，2025 考正负数意义，2026 考绝对值。复习时不能只讲计算，要能把「相反意义的量、绝对值、数轴距离」用一句话说清。
2. **第 2 题常是科学记数法 3 分题**（2022、2023、2026）。选项陷阱固定：a 写成 18 或 0.18、指数多 1 少 1。模型里必须把「a 的范围」和「n = 整数位数 - 1」做成可视化，而不是背口诀。
3. **有理数运算不单独出大题**。长春解答第 15 题多年是「先化简，再求值」，有理数运算作为底层能力嵌在里面。所以第 2 章模型按用户要求做**算理可视化**，不做刷题器；重点是符号规则与转化关系，不是题量。
4. **绝对值与数轴几乎不单独考定义，而是结合距离、大小比较出现在选择/填空**。1.2.4、1.2.5 的模型要把「距离」和「左小右大」做成一眼能看出的图。
5. **本地素材偏好**：长春卷喜欢用本地情境（地铁、机场、一汽、净月潭、人民广场）和数学史（我国最早使用正负数）。模型例题可选同类情境，但不虚构具体中考题。

**常见错因（教材 + 本地题解析归纳）**

- 认为 0 是正数或负数；认为「没有负号就是正数」（0 既不是正数也不是负数）。
- 把「相反意义的量」当成「有负号就是负数」，忽略基准。
- 认为 -a 一定是负数（a 本身可能是负数或 0）。
- 认为绝对值等于本身的数只有正数（漏掉 0）。
- 两个负数比大小，按绝对值比（-5 > -3 的错误）。
- 科学记数法里 a 不在 1 ≤ a < 10；n 数成「小数点后位数」。
- 乘方里 -2⁴ 与 (-2)⁴ 混淆；把 (-2)³ 写成 8。
- 减法只变符号不转化：-3-(-5) 写成 -3-5。
