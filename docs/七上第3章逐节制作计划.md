## 3.1 列代数式表示数量关系（旗舰，概念+列式）

核心目标：学生能说出「式子里的字母表示什么」，能把一句情境翻译成式子，也能把式子翻译回一句话。

| 板块 | 内容 | 交互 | 教材/考点依据 |
| --- | --- | --- | --- |
| 01 情境↔式子 | 机器人每秒识别 5 m²：`5t`、`n/5` | t 滑块 0–60 s；三个部位（5、t、5t）点击高亮，分别对应「效率、时间、总量」；反向切换「已知面积 n，求时间」 | 教材 3.1 引入；长春爱用真实情境 |
| 02 代数式定义 | 运算符号连接数或字母；单独一个数/字母也是 | 正反例卡片点击展开：5、t、3x、a+b 是；x+1=3、a>b、5 kg 不是 | 定义边界，必须讲清 |
| 03 同式多义 | `0.9p` 三种身份：苹果九折价、长方形面积、0.9 m/s 走 p s 的路程；`3n` 两种身份：n 个 3、边长 n 的正三角形周长 | 「换一个身份」按钮切换情境，式子不变、单位变；强调同一字母在同一情境中代表同一个量 | 教材例 1 追问；用户指定方向 |
| 04 列式翻译 | `(2n−10)`、`(1/3)a²h`、`(2a+3b)`、`8.25%a`、`(1.1x−80)`、`240/v`、`240/(v+3)`、`240/v−240/(v+3)` | 每条先显示「数量关系」再点开式子；括号处单独高亮，说明为什么加括号 | 教材例 1、例 3、例 4 |
| 05 式子→意义 | `2a+3` vs `2(a+3)`、`c/(ab)`、`x²+2x+8` | 并排两栏，点「先算谁」显示运算树；代 a=2 对比 7 与 10 | 教材例 2；易错重点 |
| 06 书写规范 | `x×y→xy`、`1a→a`、`−1ab→−ab`、`1½a→3/2a`、`m÷3→m/3`、`(2x+4y) kg`、`a×a→a²` | 每行「改写」翻转对照，显示规则一句话 | 教材书写规范五条 |
| 07 反比例 | 300 cm³ 水，底面积 x，水高 `y=300/x`；10/20/30/60 → 30/15/10/5 | x 滑块 5–100；四容器小图 + 当前水高；强调「x 变大，y 变小，xy=300」 | 教材例 5；3.1 第 3 课时 |
| 08 读一读 | 数字 1 与字母 x 的对话：字母可代表不同的数；同一情境同一字母同一含义 | 折叠阅读卡，3 条要点 | 阅读与思考 p82 |
| 09 易错 | 含等号/不等号不是代数式；`3n` 写成 `n3`；`2a+3` 与 `2(a+3)` 混；单位不加括号；带分数系数 | 6 条「错→为什么错→正确」 | 课堂真实错例 |
| 10 复述自检 | 5 问：什么是代数式；0.9p 的两种含义；2a+3 与 2(a+3)；为什么 xy 可省乘号而 m÷3 要写分数；300/x 中 x 是什么 | 文本框 + 参考表述 + 把握程度，不判分 | 概念型标准 |
| 11 中考连接 | 2023 长春第 11 题 `7.5−10x`；结论：本章多为 1 道 3 分选填，重情境理解 | 一句结论 + 一道原题回看 | 长春真题 |

明确不做：不把 3.1 做成「列式刷题器」；不引入整式加减（第 4 章）；不把反比例讲成反比例函数（九下）。

## 3.2 代数式的值（旗舰，求值+规律）

核心目标：学生能按「当…时 → 抄式 → 代值（负数、分数加括号）→ 计算」四步求值，并知道字母取值不同，值一般不同。

| 板块 | 内容 | 交互 | 依据 |
| --- | --- | --- | --- |
| 01 情境 | 排球 `5n+20`；n=15→95，n=20→120 | n 滑块 1–30，两个预设按钮 | 教材 3.2 引入 |
| 02 定义+四步 | 用数值代替代数式中的字母，按运算关系算出的结果 | 「下一步」逐步展开 2x+3y 的示范，不自动播放 | 教材定义；规范 |
| 03 滑块+取值表 | `2x+3` 与 `x²−1` 两个式子，x 从 −2 到 3 | x 滑块（−2..3，0.5 步长）；表格固定在 −2、−1、0、1、2、3；当前行高亮；**只显示数值表，不画图像**，并写明「图像到学函数才出现」 | 用户指定；章节核心 |
| 04 教材例 1 | `2x+3y`：x=15,y=12→66；x=1,y=1/2→7/2 | 两步展开，分数代入处高亮括号 | 教材 P79 例 1 |
| 05 教材例 2 | `a²−b/4`：a=4,b=12→13；a=−3,b=2→17/2 | 「找错」：把 `(−3)²` 写成 `−3²`，点出错误后给正解 | 教材 P79 例 2；最高频错因 |
| 06 教材例 3 | 跑道 `2a+πb`；a=67.3,b=52.6,π=3.14→≈300 m | a、b 滑块 + 跑道示意图；显示 2a 与 πb 各对应哪一段 | 教材 P80 例 3 |
| 07 规律：火柴棒 | 连排搭 n 个三角形需 `3+2(n−1)=2n+1` 根 | n 滑块 1–12，逐个画出三角形；表 n=1..6：3,5,7,9,11,13；强调「每多一个多用 2 根」 | 用户指定；教材数学活动式拓展 |
| 08 易错 | 负数不加括号、分数不加括号、省略乘号不还原、`2x²` 与 `(2x)²`、把值写成式子、值同不代表字母同 | 6 条对照 | 课堂错例 |
| 09 当堂检测 | 5 题：3a+1（a=−2）；2x−y（x=1/2,y=−2）；已知 a²+a=3 求 2a²+2a−1；火柴棒第 n 个；x²−2x（x=−3） | 选项即时反馈 + 统计条 + 重做；section 用 `id="quizSec"` 避免与内部 `.quiz` 重名 | 运算型标准；2025 长春第 11 题同类 |
| 10 小结/中考 | 四步口诀；2025 长春第 11 题整体代入（答案 3） | 结论卡 | 长春真题 |

明确不做：不画函数图像；不引入「代数式值域」；规律题不包装成「长春必考题型」，只作「用字母表示第 n 个」的训练。

## 技术落点

- 复用第 1、2 章 CSS 变量与组件：bar / hero / card / seg / accordion / mis-grid / self / quiz / teacher / projector / print / embed。
- 交互全部原生 JS，无外部库；滑块用 `input[type=range]`；表格与图形用 DOM/SVG。
