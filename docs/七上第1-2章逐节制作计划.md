## 第 1 章 有理数

### 1.1 正数和负数（概念解剖 · A）

| 项 | 内容 |
|---|---|
| 核心交互 | 四类情境切换（温度 / 海拔 / 收支 / 水位），一条可拖的「基准线」；输入或拖动数值后，同一件事用「+」「−」两种记法并排显示，方向箭头随正负翻转 |
| 参量 | 情境（4 选 1）、基准值（-20～20）、数值（-20～20，步长 1）、是否显示「相反记法」 |
| 教材表述 | 「像 3、50、7.8% 这样大于 0 的数叫做正数；像 -3、-10、-0.7% 这样在正数前加上符号『-』的数叫做负数」；0 既不是正数也不是负数 |
| 教材例题/素材 | 气温零上/零下；盈利与亏损；产量增长与减少；阅读与思考「用正负数表示允许偏差」（零件 10±0.05 mm） |
| 考点 | 长春 2025 第 1 题：水位下降记作负数，上升记作什么（3 分） |
| 易错点 | ① 0 是正数；② 没有负号就是正数（忽略 0）；③ 基准一换，符号跟着换却仍套旧符号；④ 把「有负号」等同于「负数」，不看它表示的量 |
| 检测 5 题 | 记忆：0 属于哪类；理解：水位升降记法；判断：「-a 一定是负数」；应用：允许偏差 +0.03 表示什么；迁移：换基准后同一量怎么记 |
| 特殊要求 | 「相反意义的量」必须成对出现，页面上始终能看到「基准」两个字，不许只丢一个负数 |

### 1.2.1 有理数的概念（概念解剖 · S，修订）

| 项 | 内容 |
|---|---|
| 本次改动 | 定义主句改为 2024 版「**可以写成分数形式的数称为有理数**」；旧说法「整数和分数统称有理数」移入「说法演变」卡片，注明是旧教材说法 |
| 核心交互 | 保留定义拆句、分类树、正反例、边界、误解、复述自检；新增「三步认识」时间轴：本章分数形式 → 第二章除法后 p/q → 统一记法 |
| 教材表述 | 整数可以写成分数形式；有限小数、无限循环小数都可以写成分数形式；π、√2 不行 |
| 教材例题/素材 | 判断给定数集里哪些是正数、负数、整数、分数；0.333… 与 1/3；22/7 与 π |
| 考点 | 长春第 1 题常以「绝对值/数轴」出现，但概念是底层；分类与「是不是有理数」是填空、选择的基础 |
| 易错点 | ① 认为分数必须带分数线；② 认为小数都不是分数；③ 认为 π 是分数（22/7 才是）；④ 把「有理数」理解成「有道理的数」 |
| 检测 | 概念型不判分；保留 5 个复述自检，参考表述按新定义改写 |

### 1.2.3 相反数（概念 + 数轴 · A）

| 项 | 内容 |
|---|---|
| 核心交互 | 数轴上一个可拖的点 a（-6～6，步长 0.5），对称点 -a 同步出现；开关「显示对称点」；右侧「多重符号化简器」：点一下剥一层负号，逐层显示 |
| 参量 | a、是否显示 -a、负号层数（1～3） |
| 教材表述 | 只有符号不同的两个数叫做互为相反数；0 的相反数是 0；a 的相反数是 -a |
| 教材例题 | 求 3、-4、0、2/3 的相反数；化简 -(-2)、-(+3)、-[-(-5)] |
| 考点 | 与 2026 第 1 题（绝对值）相邻；「-(-2026)」是长春常见选择/填空起点 |
| 易错点 | ① -a 一定是负数；② 0 没有相反数；③ 相反数与倒数混淆；④ 多重负号从右往左数错 |
| 检测 5 题 | 记忆：0 的相反数；理解：-a 的符号讨论；判断：相反数是否成对；应用：数轴找对称点；迁移：化简三层负号 |

### 1.2.4 绝对值（数轴 + 距离 · A，重点）

| 项 | 内容 |
|---|---|
| 核心交互 | 数轴拖点，点到原点的距离用线段 + 数值实时高亮；再给第二个点，比较两点到原点的距离；「|a| 与 a 的关系」三行表随 a 的正负变色 |
| 参量 | a（-6～6，步长 0.5）、b（-6～6）、是否显示距离标注 |
| 教材表述 | 数轴上表示数 a 的点与原点的距离叫做数 a 的绝对值，记作 |a|；正数的绝对值是它本身，负数的绝对值是它的相反数，0 的绝对值是 0 |
| 教材例题 | 分别写出 1、-0.5、3/2 的绝对值；数轴上 A、B、C、D 谁离原点最近；若 |x| = 3，求 x |
| 考点 | 长春 2026 第 1 题（|-2026|）；2023 第 1 题（数轴四点中绝对值最小） |
| 易错点 | ① 绝对值可以是负数；② 绝对值等于本身的数只有正数（漏 0）；③ 把 |a| 当成「去掉负号」而不看距离；④ |x|=3 只写 3 |
| 检测 5 题 | 1 记忆（|0|）；2 理解（距离含义）；3 数轴点选「绝对值最小」；4 求 |x|=3；5 迁移（|a|=-a 的条件） |

### 1.2.5 有理数的大小比较（数轴 · A）

| 项 | 内容 |
|---|---|
| 核心交互 | 数轴上两个可拖点 a、b，中间自动出现「<」或「>」；竖向温度计同步排序；勾选「只显示负数」后，突出「绝对值大的反而小」 |
| 参量 | a、b（-8～8，步长 0.5）、是否显示绝对值条 |
| 教材表述 | 在水平数轴上，左边的数小于右边的数；正数大于 0，0 大于负数，正数大于负数；两个负数，绝对值大的反而小 |
| 教材例题 | 把 -4、-3、-2、-1、0、1、2 从低到高排列；比较 -3 与 -5；比较 -(-2) 与 -|-3| |
| 考点 | 与 2023 第 1 题同一思路：先看绝对值，再看位置 |
| 易错点 | ① -5 > -3；② 0 是最小的数；③ 带括号/绝对值符号的数不先化简就比较 |
| 检测 5 题 | 1 记忆（正数>0>负数）；2 判断（-5 与 -3）；3 数轴点选；4 排序；5 迁移（-(-2) 与 -|-3|） |

## 第 2 章 有理数的运算

### 2.1.1 有理数的加法（算理 · S）

| 项 | 内容 |
|---|---|
| 核心交互 | 数轴双箭头：从 0 出发走 a，再走 b，落点即和；先让学生预测落点在原点的哪一侧，再播放；同号/异号自动切换提示；下方绝对值条对比「谁大、差多少」 |
| 参量 | a、b（-8～8，步长 0.5）、动画速度、显示绝对值条 |
| 教材表述 | 同号相加取相同符号并把绝对值相加；异号相加取绝对值较大的加数的符号，用较大绝对值减较小绝对值；互为相反数的两数相加得 0；一个数同 0 相加仍得这个数 |
| 教材例题 | (-3)+(-9)；(-8)+0；12+(-8)；(-4.7)+3.9；-1/2+1/2 |
| 考点 | 长春不单独出大题，但它是「先化简再求值」的底层；符号判断是第 1 题之外的隐性考点 |
| 易错点 | ① 异号相加符号跟第一个数；② 用「大减小」时减反；③ 互为相反数得 0 写成 2a；④ 0 参与时改变符号 |
| 检测 5 题 | 1 记忆（同号法则）；2 判断（(-7)+4 的符号）；3 数轴点选落点；4 计算（-4.7+3.9）；5 迁移（|a|=5, |b|=3 且 a<b，求 a+b） |

### 2.1.2 有理数的减法（算理 · A）

| 项 | 内容 |
|---|---|
| 核心交互 | 两条路径并排：上排「a - b」，下排「a + (-b)」，两条箭头终点重合；把「减号变加号、减数变相反数」两处高亮 |
| 参量 | a、b（-8～8，步长 0.5）、是否显示转化步骤 |
| 教材表述 | 减去一个数，等于加上这个数的相反数：a - b = a + (-b) |
| 教材例题 | 15-(-3)；0-(-7)；(-5)-(-8)；3-5；-3-5 |
| 考点 | 与加法合并考查；长春计算题里常以「减去负数」设卡 |
| 易错点 | ① 只把减号变加号，忘了减数变相反数；② 减负数仍写成减正数；③ 0 减一个数写成 0；④ 连减不逐步转化 |
| 检测 5 题 | 1 记忆（减法法则）；2 判断（3-5 的符号）；3 两步转化点选；4 计算（-5-(-8)）；5 迁移（a-b 与 b-a 的关系） |

### 2.2.1 有理数的乘法（算理 · A）

| 项 | 内容 |
|---|---|
| 核心交互 | 「重复加法」演示 a×n；负数×负数用「方向翻转」：每乘一个负数，箭头翻一次向，翻两次回正向；右侧符号规则 2×2 表随所选因数点亮 |
| 参量 | a（-5～5，步长 0.5）、n（2～5）、是否显示重复加法 |
| 教材表述 | 两数相乘，同号得正，异号得负，并把绝对值相乘；任何数同 0 相乘都得 0；乘积是 1 的两个数互为倒数 |
| 教材例题 | (-5)×(-3)；(-4)×5；0×(-7)；(-1/2)×(-2) |
| 考点 | 符号规则是后续乘方、整式乘法的基础；长春不单独大题 |
| 易错点 | ① 负负得负；② 0 乘负数得负数；③ 倒数与相反数混淆；④ 多个因数时不数负号个数 |
| 检测 5 题 | 1 记忆（同号得正）；2 判断（(-4)×5 符号）；3 翻转次数点选；4 计算（-1/2×(-2)）；5 迁移（三个负数相乘的符号） |

### 2.2.2 有理数的除法（算理 · A）

| 项 | 内容 |
|---|---|
| 核心交互 | 除法转乘法双路径：a÷b 与 a×(1/b) 终点相同；「0 作除数」按钮被禁用并给出原因；符号判断与绝对值同步显示 |
| 参量 | a（-12～12）、b（-6～6，不含 0） |
| 教材表述 | 除以一个不等于 0 的数，等于乘这个数的倒数；两数相除，同号得正，异号得负，并把绝对值相除；0 除以任何不等于 0 的数都得 0 |
| 教材例题 | (-36)÷9；(-12/25)÷(-3/5)；0÷(-2026) |
| 考点 | 学完本节后，教材才把有理数定义完善为 p/q，模型里要回扣 1.2.1 |
| 易错点 | ① 0 作除数；② 倒数的符号写反；③ 除法不转化直接「大减小」；④ 0÷0 当成 0 |
| 检测 5 题 | 1 记忆（除法法则）；2 判断（0 能否作除数）；3 转化点选；4 计算（-36÷9）；5 迁移（a÷b 与 a×1/b 的等价） |

### 2.3.1 乘方（算理 · A）

| 项 | 内容 |
|---|---|
| 核心交互 | 底数 a、指数 n 滑块；n=2 显示正方形面积、n=3 显示正方体体积；「折纸」倍增对照；「-2⁴ vs (-2)⁴」双列数值表随 n 变化 |
| 参量 | a（-3～3，步长 1）、n（1～6） |
| 教材表述 | 求 n 个相同因数的积的运算叫做乘方，乘方的结果叫做幂；负数的奇次幂是负数，偶次幂是正数；正数的任何次幂都是正数；0 的任何正整数次幂都是 0 |
| 教材例题 | (-2)³；(-2)⁴；-2⁴；(-2/3)³ |
| 考点 | 符号与括号是长春计算题的常见卡点；科学记数法的 10ⁿ 也依赖它 |
| 易错点 | ① -2⁴ = 16；② (-2)³ = 8；③ 底数为分数不加括号；④ 指数 1 与 0 混淆 |
| 检测 5 题 | 1 记忆（底数/指数）；2 判断（(-2)⁴ 符号）；3 点选（-2⁴ 的值）；4 计算（(-2/3)³）；5 迁移（n 增大时 (-2)ⁿ 的符号规律） |

### 2.3.2 科学记数法（含 2.3.3 近似数 · A，长春重点）

| 项 | 内容 |
|---|---|
| 核心交互 | 数位表 + 小数点移动动画：输入一个大于 10 的数，显示「小数点向左移几位」与 a×10ⁿ；滑杆 n 联动；最后一屏「精确到哪一位 / 有效数字」：选精确度，末位数字高亮，有效数字逐个点亮 |
| 参量 | 原数（10～10¹² 预设 + 自定义）、n、精确度（个/十/百/千/万） |
| 教材表述 | 把一个大于 10 的数表示成 a×10ⁿ（1≤a<10，n 为正整数）；n 等于整数位数减 1；近似数的精确度与有效数字 |
| 教材例题 | 1 000 000；57 000 000；38 000 000；1 800 000；3.14 精确到百分位；0.030 的有效数字 |
| 考点 | 长春 2022 第 2 题（1.8×10⁶）、2023 第 2 题（3.8×10⁷）、2026 第 2 题（1.6×10⁷） |
| 易错点 | ① a 写成 18 或 0.18；② n 多 1 少 1；③ 有效数字从最左边的 0 数起；④ 近似数末尾的 0 被去掉 |
| 检测 5 题 | 1 记忆（a 的范围）；2 判断（18×10⁵ 是否规范）；3 点选（16 000 000 的记法）；4 精确度（3.14）；5 迁移（有效数字个数） |
