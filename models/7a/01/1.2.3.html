只有符号不同的两个数叫做互为相反数。在数轴上，它们分别在原点两侧，到原点的距离相等。

a = 0 时，−a 也是 0：0 的相反数是 0。这不是「没有相反数」，而是它和自己重合。

03

教材例题

先自己写，再展开。

例：分别写出 3、−4、0、2/3 的相反数。

3 的相反数是 −3；−4 的相反数是 4；0 的相反数是 0；2/3 的相反数是 −2/3。

要点：求相反数就是改符号；0 改完还是 0。

例：化简 −(−2)、−(+3)、−[−(−5)]。

−(−2) = 2；−(+3) = −3；−[−(−5)] = −5。

方法：从最里面往外剥，每剥一层负号，符号就翻一次；也可以数负号个数，奇数个得负，偶数个得正。

变式：如果 a 是负数，−a 是什么数？

−a 是正数。比如 a = −4，则 −a = 4。所以「−a 一定是负数」是错的：−a 的符号要看 a 本身。

变式：一个数的相反数是它本身，这个数是多少？

只有 0。因为 a 与 −a 要在数轴上重合，只能都在原点。

04

四个常见误解

误解 01

「−a 一定是负数。」

a 可能是负数或 0：a = −4 时 −a = 4；a = 0 时 −a = 0。−a 只是「a 的相反数」这个写法。

误解 02

「0 没有相反数。」

0 的相反数是 0。它和自己重合，但确实满足「只有符号不同」的特殊情形。

误解 03

「相反数就是倒数。」

相反数是和为 0（3 与 −3）；倒数是积为 1（3 与 1/3）。两回事。

误解 04

「负号越多，数越小。」

要看负号个数的奇偶：−(−3) = 3，−(−(−3)) = −3。先化简，再判断大小。

05

复述自检：不判分

先自己说，再对照。输入只在本机内存，刷新即清空。

1. 用自己的话说：什么样的两个数叫互为相反数？

参考：只有符号不同的两个数叫做互为相反数；在数轴上，它们在原点两侧，到原点的距离相等。

2. 0 的相反数是多少？为什么不是「没有」？

参考：0 的相反数是 0。0 在原点，对称点还是原点，所以它和自己重合。

3. 如果 a 是负数，−a 是什么数？举例说明。

参考：−a 是正数。例如 a = −4，则 −a = 4。所以不能看到「−a」就说它是负数。

4. 化简 −[−(−5)]，并说清每一步。

参考：先算最里面 −(−5) = 5，再算 −[5] = −5。也可以数负号：三个负号，奇数个，结果是负。

5. 相反数和倒数有什么不同？

参考：相反数的和为 0（3 与 −3）；倒数的积为 1（3 与 1/3）。0 有相反数 0，但没有倒数。

教师模式 · 1.2.3

2024 人教版七上第 1 章；核对 2026-11-26。按 T 开关。

本节目标

学生能在数轴上找到相反数，说清「只有符号不同」，并会化简多重符号。

3 分钟开场

「3 和 −3 差在哪？只差一个负号。可如果我问：−a 一定是负数吗？很多同学会点头。今天我们就把这个『−』看清楚：它到底是负号，还是『相反数』的记号。」

5 个追问

  1. 「0 的相反数是多少？」期望：0。
  2. 「a = −4 时，−a 是多少？」期望：4。
  3. 「相反数和倒数差在哪？」期望：和為 0 vs 积为 1。
  4. 「−(−3) 等于几？为什么？」期望：3，两个负号抵消。
  5. 「数轴上互为相反数的两点有什么位置关系？」期望：关于原点对称、距离相等。

常见反应

① 「−a 就是负数」——用滑块把 a 拖到负半轴。
② 「0 没有相反数」——看 a=0 时两点重合。
③ 「负号越多越小」——用化简器数奇偶。
