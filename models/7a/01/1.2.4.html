绝对值 数轴上到原点的距离

数轴 + 距离 5 题当堂检测 长春第 1 题落点 单文件 · 断网可用

拖点 a：|a| 就是它到原点的距离。距离没有负的——先把这件事看进眼里。

01

距离，不是「去掉负号」

拖动点或在右边调滑块，橙色线段就是 |a|。再把第二个点拖出来比一比。

同一条橙色线段，从原点量到点；长度就是绝对值。

|a| 是距离，所以 |a| ≥ 0。a 是正数时 |a| = a；a 是负数时 |a| = −a；a = 0 时 |a| = 0。

易错：|−3| = 3，不是 −3。距离不是「把负号搬到前面」，而是「不管在哪边，都量到原点」。

02

定义与三条结论

定义只有一句，但要能拆成「距离」和「记法」两件事。

数轴上表示数 a 的点与的 ，叫做数 a 的绝对值，记作 。

点一段，看它容易错在哪。

a 的情况|a| 等于什么举例
a > 0|a| = a|5| = 5
a = 0|a| = 0|0| = 0
a < 0|a| = −a|−5| = 5
绝对值一定是非负数：|a| ≥ 0。反过来也要会：若 |a| = a，则 a ≥ 0；若 |a| = −a，则 a ≤ 0。
03

教材例题

先自己写，再展开对照。

例：分别写出 1、−0.5、3/2 的绝对值。

|1| = 1；|−0.5| = 0.5；|3/2| = 3/2。

前两个看距离；最后一个本身是正数，绝对值就是它自己。

例：数轴上点 A、B、C、D 分别表示 −3.5、−1、0.5、2.5，谁离原点最近？

分别求绝对值：3.5、1、0.5、2.5。点 C 离原点最近，因为 |0.5| 最小。

方法：比较谁离原点近，就是比较绝对值的大小，不看正负。

例：若 |x| = 3，求 x。

x = 3 或 −3。数轴上到原点距离为 3 的点有两个，一左一右。只写 3 会漏解。

长春连接：2026 年第 1 题求 |−2026|。

|−2026| = 2026。这是 3 分选择题，考的就是「距离非负」这一条。看到绝对值，先问：它到原点多远？

04

四个常见误解

误解 01

「绝对值可以是负数。」

绝对值是距离，距离最小是 0。|a| ≥ 0，永远不可能小于 0。

误解 02

「绝对值等于本身的数只有正数。」

漏了 0。|0| = 0，0 也等于它本身。正确答案是非负数。

误解 03

「|−3| 就是 −3。」

−3 到原点的距离是 3，所以 |−3| = 3。绝对值不是「把数原样抄下来」。

误解 04

「|x| = 3，所以 x = 3。」

还漏了 −3。数轴上距离为 3 的点有两个，除非题目另有限制。

教师模式 · 1.2.4

2024 人教版七上第 1 章；核对 2026-11-26。按 T 开关。

本节目标

学生能把 |a| 解释成「到原点的距离」，会求绝对值，知道 |a| ≥ 0，并会用绝对值比较「谁离原点近」。

3 分钟开场

「−3 和 3 谁大？3 大。可如果我问：谁离 0 更近？一样近。今天学的绝对值，量的就是『离 0 多远』，不是『谁大』。」

5 个追问

  1. 「|0| 是多少？」期望：0。
  2. 「绝对值可能是负数吗？」期望：不可能，距离非负。
  3. 「|−2026| 是多少？」期望：2026。
  4. 「|x| = 3，x 有几个？」期望：两个，±3。
  5. 「|a| = −a，a 是什么范围？」期望：a ≤ 0。

常见反应

① 「绝对值就是去掉负号」——用数轴距离纠正。
② 「等于本身的只有正数」——把 a 拖到 0。
③ 「|x|=3 只有 3」——看数轴两侧。

衔接

模型停在 01 屏与表格；接着板书三条结论，再做 4 个口答：|−7|、|0|、|2.5|、|−1/2|。
