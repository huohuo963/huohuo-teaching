01

在数轴上，位置就是大小

水平数轴看左右；右边的温度计看上下。两种摆法，结论一致。

数轴上越靠右越大；温度计上越靠上越高。两个负数的比较最容易反。

两个负数：绝对值大的那个，反而更小。
在水平数轴上，左边的数小于右边的数。正数大于 0，0 大于负数，正数大于负数；两个负数，绝对值大的反而小。

例：−5 与 −3。|−5| = 5，|−3| = 3，5 > 3，所以 −5 < −3。绝对值大，说明它离原点更远，位置更靠左。

03

教材例题

先自己排、自己比，再展开。

例：把 −4、−3、−2、−1、0、1、2 按从低到高的顺序排列。

−4 < −3 < −2 < −1 < 0 < 1 < 2。它们正好是数轴上从左到右的一串点；温度计上就是从下到上。

例：比较 −3 与 −5 的大小。

−3 > −5。因为 |−3| = 3，|−5| = 5，两个负数绝对值大的反而小，所以 −5 更小。

易错：不要因为 5 > 3 就写 −5 > −3。

例：比较 −(−2) 与 −|−3|。

先化简：−(−2) = 2，−|−3| = −3。所以 2 > −3。

方法：带括号或绝对值符号的数，先化成最简形式再比。

长春连接：2023 年第 1 题「数轴上四点中绝对值最小」。

先看各点到原点的距离（绝对值），再比较距离大小。绝对值最小，就是离原点最近；不要把它和「数最小」混为一谈。

04

三个常见误解

误解 01

「−5 > −3，因为 5 > 3。」

两个负数比大小，绝对值大的反而小。−5 在 −3 左边，所以 −5 < −3。

误解 02

「0 是最小的数。」

负半轴上的数都比 0 小。0 只是正数和负数的分界，不是最小的数。

误解 03

「−(−2) 一定比 −3 小。」

先化简：−(−2) = 2，2 > −3。带符号的数不化简就比较，是常见失分点。

本节目标

学生能用数轴比较有理数大小，记住「左小右大」，并会说清「两个负数绝对值大的反而小」。

3 分钟开场

「−5 和 −3 谁大？有人说 5 比 3 大，所以 −5 大。我们把它俩放到数轴上看看：谁在左边？左边的小。今天就用数轴把这件事一次说清。」

5 个追问

  1. 「数轴上左边的数大还是小？」期望：小。
  2. 「0 是最小的数吗？」期望：不是，负数更小。
  3. 「−5 和 −3 谁大？」期望：−3 大。
  4. 「−(−2) 和 −|−3| 谁大？」期望：2 > −3。
  5. 「绝对值最小的数是不是最小的数？」期望：不是，绝对值看远近。

常见反应

① 用绝对值直接比负数——把 a、b 拖到两个负数，看位置。
② 0 最小——拖到负半轴。
③ 不化简就比——用例题 −(−2)。
