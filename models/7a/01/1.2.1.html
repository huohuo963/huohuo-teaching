有理数的概念不是「有道理的数」，是「能写成两个整数之比的数」。

本节只追一件事：合上书，你能用自己的话把「什么是有理数」讲给同桌听。

01

先把定义原文读三遍

教材原句：整数和分数统称有理数。点下面三个词，看它们各自管什么。

和 有理数。

点一个词，看看它在定义里承担什么任务。

02

先猜一猜，再看解释

不判对错。先把你现在的想法选出来，再往下看它为什么归到那一类。

0.25 应该归到哪一类？

03

定义长成一棵树

有理数先分成整数和分数两支；每一支下面再分。注意 0 的位置。

有理数

整数

正整数 1, 2, 3 … 0 既不是正数，也不是负数 负整数 −1, −2, −3 …

0 是整数，所以 0 也是有理数。这一点最容易被漏掉。

分数

正分数 1/2, 0.25 … 负分数 −1/3, −0.6 …

有限小数和无限循环小数，都能写成分数，所以它们也在这支里。

04

正例和反例，各看几个

点每个数，展开一句「为什么」。正例看它怎么写成整数或分数；反例看它为什么写不成。

这些是有理数

整数，或能写成两个整数之比的数。

这些不是有理数

无限不循环小数，写不成两个整数之比。

「有规律」不等于「循环」；循环要求同一段数字不断重复。

04b

教材例题回看

教材里的分类题，重点不是把格子填满，而是每一条理由都能说清。

例 1：把 −7、0.32、1/3、0、−3.5、π 填进有理数集合

有理数有：−7、0.32、1/3、0、−3.5。π 不是有理数。

理由：−7 和 0 是整数；0.32 = 8/25，1/3 本身是分数，−3.5 = −7/2，都能写成两个整数之比。π 是无限不循环小数，写不成分数。

例 2：判断下面四句话

① 0 是有理数。② −7 是整数。③ 0.333… 是分数。④ π 是分数。

答案：① 对，0 是整数；② 对，−7 是负整数；③ 对，0.333… = 1/3；④ 错，π 是无限不循环小数，不是分数。

变式：0.1010010001… 是有理数吗？

不是。它虽然有规律，但同一段数字不循环，不能写成两个整数之比。判断有理数只看「能不能写成分数」，不看「有没有规律」。

变式：−0.6 和 −3/5 是同一个数吗？

是同一个数，−0.6 = −3/5。一个是小数写法，一个是分数写法；两种写法都不影响它是有理数。

05

边界情形：最容易含糊的地方

每条先自己回答，再点开对照。答不出来不丢人，这里本来就是用来暴露含糊的。

0 是有理数吗？它特殊在哪？

是。0 是整数，而整数都属于有理数。它特殊在：既不是正数，也不是负数；但它是地地道道的有理数。

−7 为什么既在整数里，又在有理数里？

因为整数是有理数的一部分。−7 是负整数，所以它先属于整数，再被「统称」进有理数。不是两个并列的标签，而是包含关系。

0.5 和 1/2 是同一个数吗？

是同一个数，只是两种写法。0.5 = 1/2。判断是不是有理数，看它能不能写成两个整数之比，不看它长什么样。

22/7 和 π 有什么区别？

22/7 是分数，分子分母都是整数，所以它是有理数；π 是无限不循环小数，不是有理数。22/7 ≈ 3.142857… 只是 π 的近似值，不能写成「π = 22/7」。

分数一定带分数线吗？

不一定。0.25、−0.6、0.333… 都没有分数线，但它们都能写成分数，所以都归在分数这一类。「分数」看的是能不能写成两个整数之比，不是看外形。

0.333… 为什么是有理数？

因为它等于 1/3，能写成两个整数之比。它是无限循环小数，循环节是 3；无限循环小数都可以化成分数。

06

四个常见误解

这些不是编出来的错，是课堂上真的会听到的说法。每条都配一句「为什么错」。

误解 01

「有理数就是有道理的数。」

名称来自英文 rational number，词根是 ratio（比），不是「有道理」。有理数 = 能写成两个整数之比的数。

误解 02

「分数一定带分数线。」

0.25、0.333… 都没有分数线，却能写成分数。看本质，不看外形。

误解 03

「小数都不是分数。」

有限小数和无限循环小数都能化成分数；只有无限不循环小数才不是有理数。不能把所有小数一刀切。

误解 04

「0 既不是正数也不是负数，所以不是有理数。」

0 是整数，整数都属于有理数。正负号和有理数是两套不同的分类。

误解 05

「π = 22/7。」

22/7 是 π 的近似值，不是相等。π 是无限不循环小数，写不成分数。

误解 06

「有规律的小数都是循环小数。」

0.1010010001… 有规律，但同一段数字不重复，所以不循环，不是有理数。

07

两种表征：分类树和数轴

分类树回答「它属于哪一类」；数轴回答「它在哪儿」。有理数都能在数轴上找到点，但数轴上不只有有理数。

有理数：−7、0、0.25、1/2、0.333… 不是有理数：π、√2
整数和分数统称有理数。判断一个数是不是有理数，只看一件事：能不能写成两个整数之比。

迁移问题：π 能不能写成分数？如果有人说「π = 22/7」，你打算怎么回应他？

中考连接：有理数分类、无理数识别常在选择题前两题出现；判断标准仍然是「能不能写成两个整数之比」。

教师模式 · 1.2.1

2024 人教版七上第 1 章；核对 2026-11-26。按 T 可随时开关。

本节目标

学生能用自己的话解释「整数和分数统称有理数」，并能判断 0、负整数、有限小数、循环小数、π 这几类数。

3 分钟开场（可直接念）

「今天不急着算。我先问一个看起来很简单的问题：什么是有理数？你先别翻书，用自己的话说一句。很多同学会说『有道理的数』——这个名字确实容易误会。我们今天就把这句话拆开，看看它到底在说什么。」

5 个追问（按顺序）

  1. 「整数有哪些？」期望：正整数、0、负整数。
  2. 「0 是整数吗？那它是有理数吗？」期望：是，整数都属于有理数。
  3. 「0.25 是分数吗？它没有分数线啊。」期望：0.25 = 1/4，能写成分数。
  4. 「0.333… 呢？它写不完。」期望：等于 1/3，是循环小数，能化成分数。
  5. 「π 呢？22/7 不是它的分数形式吗？」期望：22/7 只是近似值，π 无限不循环，不能写成分数。

3 个预设场景

标准例：从定义和正例开始；易错例：直接看四个误解；挑战例：跳到复述自检。

常见学生反应

  1. 「有理数就是有道理的数。」→ 回到英文 ratio，说明名称来源。
  2. 「小数都不是分数。」→ 让他把 0.25 写成 1/4，再看 0.333…。
  3. 「0 什么都不是。」→ 先确认 0 是整数，再确认整数属于有理数。

与板书、题单的衔接

模型用到「正例 / 反例」停，接着在黑板画分类树；题单只做「判断并说理由」，不要求写长篇。
