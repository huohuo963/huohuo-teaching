等式的性质 · 2024 人教版 · 七上第 5 章

等式的性质把等式想成一架天平：两边同时做同样的事，天平才继续平衡。解方程的所有变形，都从这里来。

天平主线 概念 + 操作 · 不判分 5.1 方程（教材约 3 课时） 单文件 · 断网可用

本节只追三件事：能说清等式两边为什么必须做同样的运算；能说出性质 1、2 的条件；能用性质解简单方程，并说出每一步的依据。

01

天平与等式：动一边，另一边也要动

左边一个袋子，里面装着未知数 x；右边 5 个单位。天平现在平衡，说明 x = 5。试试对两边做同样的操作。

x = 5左边 1 个 x，右边 5 个单位；天平平衡

关键：天平平衡表示「左边 = 右边」。对一边加了东西，另一边不加，平衡立刻被破坏；两边加同样多，仍然平衡。等式也是这样——这就是等式性质的全部直觉。

02

先记住两个基本事实

2024 版教材在性质之前先给出两个基本事实，它们是后面推理的起点。

① 等式两边可以交换

如果 a = b，那么 b = a。等号两边地位平等，左右可以互换。

a = b ⇔ b = a

② 相等关系可以传递

如果 a = b，且 b = c，那么 a = c。两个量都等于第三个量，它们就相等。

a = b，b = c ⇒ a = c

这两条看起来「显然」，但列方程时经常用：同一个量用两个式子表示，它们就相等；两个式子都等于第三个量，它们也相等。

03

性质 1：两边加（或减）同一个数（或式子）

等式两边加（或减）同一个数（或式子），结果仍相等。

如果 a = b，那么 a ± c = b ± c。注意：加或减的必须是同一个数或同一个式子。

用性质解 x + 7 = 26：想让左边只剩 x，就要把 +7 去掉；两边同时减 7。

x + 7 = 26

两边同时减 7：x + 7 − 7 = 26 − 7

左边只剩 x，右边算得 19

x = 19

依据：等式的性质 1。两边减的是同一个数 7，所以等式仍成立。

检验：把 x=19 代入原方程，左边 19+7=26，右边 26，左边=右边，所以 x=19 是解。

04

性质 2：两边乘同一个数，或除以同一个不为 0 的数

等式两边乘同一个数，或除以同一个不为 0 的数，结果仍相等。

如果 a = b，那么 ac = bc；如果 a = b（c ≠ 0），那么 a/c = b/c。

例 1：解 −5x = 20。系数是 −5，两边同除以 −5，左边只剩 x。

−5x = 20

两边同除以 −5：(−5x) ÷ (−5) = 20 ÷ (−5)

x = −4

依据：等式的性质 2。除数是 −5，不是 0；两边除的是同一个数。

例 2：解 −(1/3)x − 5 = 4。先用性质 1 去掉 −5，再用性质 2 把系数化成 1。

−(1/3)x − 5 = 4

两边同时加 5：−(1/3)x = 4 + 5

−(1/3)x = 9

两边同乘 −3：x = 9 × (−3)

x = −27

依据：第一步用性质 1（两边加 5），第二步用性质 2（两边乘 −3）。

05

这一步能用吗：只认「同一个」和「不为 0」

下面每个变形都只做了一步。判断它在解方程时能不能用，再看依据。

点一个变形，看它能不能用。

06

五个常见错误

这一节的错，几乎都能归到「没有做同样的事」或「忽略了 0」。

错误 01

左边加 3，右边减 3

不是同一种运算，等式被破坏。必须两边都加 3或两边都减 3。

错误 02

只给一边乘 2

性质 2 要求两边同乘。只乘一边，等号就不再成立。

错误 03

两边同时除以 0

0 不能作除数。性质 2 明确写「除以同一个不为 0 的数」。

错误 04

两边加的不是同一个数

左边加 5、右边加 3，即使碰巧算对，也不是等式性质，过程不合法。

错误 05

以为只能加「数」

性质 1 加或减的可以是同一个式子，如两边同时加 b；性质 2 乘除的才是数。

07

复述自检：把「依据」说出来

不判分。先自己写，再对照参考表述。解方程时说不清依据，迟早会在移项、去分母上出错。

参考：等式两边加（或减）同一个数（或式子），结果仍相等。符号：如果 a=b，那么 a±c=b±c。
参考：因为 0 不能作除数。如果两边都除以 0，运算本身没有意义，所以性质 2 要求除数不为 0。
参考：两边同时减 7，依据是等式的性质 1；减的是同一个数 7，所以等式仍成立，得 x=19。
08

小结与中考连接

等式像天平：两边同加同减、同乘同除（除数不为 0），仍然平衡。解方程就是把方程一步步化成 x=m，每一步都必须说得出依据。

最容易丢分的地方：只动一边；两边加的不是同一个；除以 0；把「两边平方」当成等式性质；解完不检验。

长春真题回看：
2022 第 11 题（3 分）：车间人数调配，设第二车间 x 人，列 (4/5)x−30+10=(3/4)(x−10)，解得 x=250，第一车间 170 人。列方程后，解方程用的就是本节的性质。
2024 第 17 题（6 分）：盈不足问题，设人数 x，列 400x−3400=300x−100，解得 33 人。移项、合并、系数化 1，每一步都靠等式性质。

命题落点：长春不单独考「等式的性质」概念题，但填空、第 17/18 题的方程求解全靠它。性质不清，移项就只会背「变号」，一去分母就漏乘。

教师模式 · 5.1.2

2024 人教版七上第 5 章，教材 5.1 方程约 3 课时，本节是其中第二部分。核对日期 2026-11-28。

本节目标

学生能用天平解释等式性质，能说出性质 1、2 的文字与符号表述，能用性质解简单方程并说出每一步依据。

3 分钟开场（可直接念）

「看这架天平，左边一个袋子装着 x，右边 5 个单位，平衡，说明 x=5。现在我往左边加 1 个，右边不动，会怎样？不平衡了。要想继续平衡，右边也得加 1。等式就是天平：两边同时做同样的事，等号才继续成立。」

5 个追问（按顺序）

  1. 「两边加的数不一样行不行？」期望：不行，必须是同一个数或同一个式子。
  2. 「两边都乘 0 行不行？」期望：虽然 0=0，但未知数信息丢了，不能用来解方程。
  3. 「性质 2 为什么不能除以 0？」期望：0 不能作除数。
  4. 「x+7=26 为什么两边减 7？」期望：让左边只剩 x，依据性质 1。
  5. 「解完为什么要检验？」期望：确认左右两边相等，防止变形出错。

3 个预设场景

标准例：先玩天平，再做 x+7=26；易错例：直接看「这一步能用吗」；挑战例：跳到 −(1/3)x−5=4。

常见学生反应

  1. 「移项就是变号。」→ 追问「为什么变号」，让他说出两边同时减同一个项。
  2. 「两边加什么都行。」→ 用天平面板演示只加一边，立刻倾斜。
  3. 「除以 0 只是算不出来。」→ 明确 0 不能作除数，性质 2 的条件不能丢。
  4. 「检验可做可不做。」→ 让他在 x+7=26 里代 18，看左右不等。

与板书、题单的衔接

板书两行：性质 1（两边同加同减同一个数或式子）；性质 2（两边同乘同一个数，或同除同一个不为 0 的数）。题单 6 题：4 题判断合法性、2 题用性质解方程。

课后 1 题

用等式的性质解 −(1/3)x−5=4，并写出每一步依据。答案 x=−27：两边加 5（性质 1），得 −(1/3)x=9；两边乘 −3（性质 2），得 x=−27。

长春落点

长春卷不单独考性质概念，但 2022 第 11 题、2024 第 17 题的方程求解全靠它。本节要把「每一步有依据」的习惯立起来，为 5.2 的移项、去分母打底。
