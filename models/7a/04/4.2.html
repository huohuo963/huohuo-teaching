运算与算理 · 2024 人教版 · 七上第 4 章

整式的加法与减法不是背「负号全变」，而是用分配律把括号外的因数乘到每一项。

S 旗舰样板 运算型 · 5 题检测 3 课时内容（合并 · 去括号 · 加减） 单文件 · 断网可用

本节只追一件事：你能按「去括号 → 找同类项 → 合并」把整式化到最简，并说清每一步的依据是分配律。

01

先看数，再看式：同一条分配律

港珠澳大桥问题 (2) 得到 72a+120a。计算它之前，先看熟悉的数：72×2+120×2。把方框里的数换成 a，算法一样吗？

72 × □ + 120 × □ = (72 + 120) × □
72×2 + 120×2 = 144 + 240 = 384先各自乘，再把积相加；也可以先加 72+120=192，再乘 2

关键：字母 a 表示数，所以数的分配律对含字母的式子同样成立。72a 与 120a 是同类项，可以合成 (72+120)a = 192a。这就是「数式通性」。

回到大桥：口岸到东人工岛 96×1.25a = 120a，海底隧道 72a，两段路程一共 72a+120a = 192a km。a = 1 时是 192 km，与第 01 节算出的数值一致。

02

同类项：字母相同，指数也相同

所含字母相同，并且相同字母的指数也相同的项，叫做同类项。几个常数项也是同类项。

两相同：字母相同、相同字母的指数相同。两无关：与系数无关、与字母顺序无关。

03

合并同类项：系数相加，字母不变

把多项式中的同类项合并成一项，叫做合并同类项。法则：系数相加，所得结果作为系数，字母连同它的指数不变。

合并同类项，本质是逆用分配律：4a² − 4a² = (4−4)a² = 0·a² = 0。

4a² + 3b² + 2ab − 4a² − 4b²

找同类项：4a² 与 −4a²；3b² 与 −4b²；2ab 没有同伴。

交换、结合：(4a² − 4a²) + (3b² − 4b²) + 2ab

系数相加：(4−4)a² + (3−4)b² + 2ab

= 0·a² + (−1)b² + 2ab

= −b² + 2ab

注意：字母和指数全程没变；2ab 与 b² 不是同类项，不能再并。

04

教材例：先合并，再看结果

两问都只做一件事：找到同类项，把系数相加，字母部分照抄。

（1）合并 xy² − 1/5 xy²

两项字母都是 x、y，y 的指数都是 2，是同类项。系数是 1 与 −1/5。

xy² − 1/5 xy²
= (1 − 1/5) xy²
= 4/5 xy²

提醒：xy² 前面的系数是 1，不是 0；写的时候要把 1 补出来再减。

（2）合并 4a² + 3b² + 2ab − 4a² − 4b²
4a² + 3b² + 2ab − 4a² − 4b²
= (4−4)a² + (3−4)b² + 2ab
= −b² + 2ab

提醒：系数相加时要把符号带上：3 + (−4) = −1；4 + (−4) = 0，这一项直接消失，不是写成 0a²。

05

先化简，再求值：为什么要多这一步

同一个式子，直接代入和先化简，结果一样，但过程长度差很多。切换看看。

例：求 2x² − 5x + x² + 4x − 3x² − 2 的值，其中 x = 1/2。

原式 = (2+1−3)x² + (−5+4)x − 2
= 0·x² − x − 2
= −x − 2
当 x = 1/2 时，原式 = −1/2 − 2 = −5/2

先合并的好处：六项变成两项，代值时只算一次乘法和一次减法。

同一个式子，直接代入 x = 1/2：

2×(1/2)² − 5×(1/2) + (1/2)² + 4×(1/2) − 3×(1/2)² − 2
= 2×1/4 − 5/2 + 1/4 + 2 − 3×1/4 − 2
= 1/2 − 5/2 + 1/4 + 2 − 3/4 − 2
= −5/2

结果一样，但：六个分数要算，每一步都可能错。先化简再求值不是形式要求，是在减少计算量。

再看一题：3a + abc − 1/3 c² − 3a + 1/3 c²，其中 a = −1/6，b = 2，c = −3

先找同类项：3a 与 −3a；−1/3 c² 与 1/3 c²；abc 没有同伴。

原式 = (3−3)a + abc + (−1/3 + 1/3)c²
= abc
当 a = −1/6，b = 2，c = −3 时，
原式 = (−1/6)×2×(−3) = 1

提醒：化简后只剩 abc，这说明原式里很多项是「互相抵消」的；如果直接代入，会白算很多。

06

去括号：括号外的因数乘每一项

2024 版教材的表述：一般地，一个数与一个多项式相乘，需要去括号，去括号就是用括号外的因数乘括号内的每一项，再把所得的积相加。

去括号的依据是分配律，不是口诀。符号变不变，是乘出来的结果。

+(a + b) = +1×(a+b) = a + b

−(a + b) = −1×(a+b) = −a − b

−(a − b) = −1×(a−b) = −a + b

最容易错的一条：−(a−b) 里，−1 要乘 a，也要乘 −b；(−1)×(−b) = +b，所以结果是 −a+b，不是 −a−b。

跟着做：去括号 −3(1 − 2y)。

−3(1 − 2y)

括号外的因数是 −3，括号内有两项：1 与 −2y。

−3 × 1 = −3

−3 × (−2y) = +6y

= −3 + 6y

不是「负号全变」四个字，而是 −3 分别乘了两项；第二项两个负号相乘得正。

07

教材例：去括号后再合并

括号前什么都没有，就是「+1 乘」；括号前是减号，就是「−1 乘」。

（1）化简 8a + 2b + (5a − b)

(5a−b) 前面是加号，相当于 +1×(5a−b)，括号内符号都不变。

8a + 2b + (5a − b)
= 8a + 2b + 5a − b
= (8+5)a + (2−1)b
= 13a + b
（2）化简 (4y − 5) − 3(1 − 2y)

−3 要乘括号里的 1 和 −2y 两项，不能只乘第一项。

(4y − 5) − 3(1 − 2y)
= 4y − 5 − 3 + 6y
= (4+6)y + (−5−3)
= 10y − 8

检查：去括号后一共四项，合并成两项；如果只剩三项，多半是漏乘了。

08

教材例：两船相距多远

甲、乙两船同时从 A 港出发，甲顺水、乙逆水，静水速度都是 50 km/h，水流速度是 a km/h。1 小时后两船相距多少？

0 km/h
甲 (50+0) + 乙 (50−0) = 50 + 50 = 100 km两船相距 100 km，与水速 a 无关

算理：甲顺水速度 (50+a) km/h，1 小时走 (50+a) km；乙逆水速度 (50−a) km/h，1 小时走 (50−a) km。相距 = (50+a) + (50−a) = 100 km。a 被抵消了，所以不管水速多大，两船都相距 100 km。

09

整式的加减：三步走

几个整式相加减，通常用括号把每个整式括起来，再去括号、合并同类项。

第一步 去括号 → 第二步 找同类项 → 第三步 合并。结果仍然是整式。

教材例：计算

(1) (2x − 3y) + (5x + 4y)
= 2x − 3y + 5x + 4y
= 7x + y

(2) (8a − 7b) − (4a − 5b)
= 8a − 7b − 4a + 5b
= 4a − 2b

第 (2) 问的关键：减号后面整个括号都要变号，−(−5b) = +5b；只把 4a 变号就错了。

教材例：大、小两个长方体纸盒的用料

小纸盒长 a、宽 b、高 c；大纸盒长 1.5a、宽 2b、高 2c（单位：cm）。用料就是表面积。

小盒：2(ab + bc + ac)
大盒：2(1.5a·2b + 2b·2c + 1.5a·2c)
　　= 2(3ab + 4bc + 3ac)
　　= 6ab + 8bc + 6ac

(1) 共用料：2(ab+bc+ac) + 6ab+8bc+6ac = 8ab + 10bc + 8ac（cm²）。

(2) 大盒比小盒多用料：(6ab+8bc+6ac) − 2(ab+bc+ac) = 4ab + 6bc + 4ac（cm²）。

提醒：减去 2(ab+bc+ac) 时，2 要乘括号里的三项，三项都要变号。

教材习题里的「与字母无关」：5 − (−3a+3) + (−a−2) − 2a + 2035
原式 = 5 + 3a − 3 − a − 2 − 2a + 2035
= (3−1−2)a + (5−3−2+2035)
= 2035

化简后 a 的系数是 0，所以 a 取任意有理数，结果都是 2035。这也是「去括号 + 合并」的直接应用。

10

数学活动：月历中的奥秘

2024 版本章数学活动有两个：活动 1 月历中的奥秘，活动 2 自然数被 3 整除的规律。它们都在做同一件事——用字母表示，再用整式运算说明道理。

活动 1：在月历上任意框出 3×3 的九个数，它们的和与中间的数有什么关系？

3
九个数的和 = 9 × 中间数中间数是 n+8，和是 9(n+8)

用字母说明：设左上角为 n，九个数是 n、n+1、n+2；n+7、n+8、n+9；n+14、n+15、n+16。相加得 9n+72 = 9(n+8)，正好是中间数的 9 倍。换一个框，结论仍然成立，因为字母 n 代表任意位置。

活动 2：为什么「各数位数字之和能被 3 整除，这个数就能被 3 整除」？

以两位数 ab（a 是十位、b 是个位）为例：

ab = 10a + b = 9a + (a + b)

9a 一定能被 3 整除；所以只要 a+b 能被 3 整除，9a+(a+b) 就能被 3 整除。

三位数 abc = 100a+10b+c = 99a+9b+(a+b+c) = 3(33a+3b)+(a+b+c)。同理，只要 a+b+c 能被 3 整除，这个三位数就能被 3 整除。

11

六个常见错误

整式加减的错，八成集中在「去括号漏乘」和「强行合并」两类。

错误 01

−(a−b) = −a−b

−1 要乘两项：(−1)×(−b)=+b，正确结果是 −a+b。

错误 02

−3(1−2y) = −3−2y

−3 只乘了第一项。第二项是 (−3)×(−2y)=+6y，结果 −3+6y。

错误 03

2a+3b = 5ab

2a 与 3b 不是同类项，不能合并；结果就是 2a+3b。

错误 04

3x²−x² = 3

系数 3−1=2，字母部分 x² 不变，结果是 2x²，不是 3。

错误 05

2x²+3x² = 5x⁴

合并时指数不变，只加系数，结果是 5x²。

错误 06

去括号后忘记合并

去括号只是第一步，最后要按同类项合并到最简；答案写成 4y−5−3+6y 不算完成。

小结与中考连接

整式加减只有三步：去括号（分配律）→ 找同类项 → 合并（系数相加，字母不变）。化简求值先化简、再代入，能少算很多步。

最容易丢分的地方：减号后面只变第一项、括号外有系数只乘第一项、把非同类项硬合并、合并时动了字母指数。

长春真题回看：
2024 第 9 题（填空 3 分）：单项式 −2a²b 的次数是 3，属本章概念。
2025 第 10 题（填空 3 分）：写出一个与 a²b 同类的项，答案开放，如 2a²b、−a²b。
2022 第 15 题（6 分）：先化简再求值 (2+a)(2−a)+a(a+1)，化简得 a+4，a=√2−4 时原式 = √2。
2023 第 15 题（6 分）：(a+1)²+a(1−a) 化简得 3a+1，a=√3/3 时原式 = √3+1。
2025 第 15 题（6 分）：(1+x)²−2x 化简得 x²+1，x=√3 时原式 = 4。

教师模式 · 4.2

2024 人教版七上第 4 章，教材安排约 3 课时（合并同类项、去括号、整式加减）。核对日期 2026-11-26。

本节目标

学生能判断同类项、按法则合并；能说出去括号的依据是分配律，并正确乘到括号内每一项；能按三步完成整式加减与化简求值。

3 分钟开场（可直接念）

「72×2+120×2 你会算：先加 72 和 120，再乘 2。现在把 2 换成 a，72a+120a 能不能也这么算？能，因为 a 表示数。今天我们就用这条分配律，把整式的加减打通。」

5 个追问（按顺序）

  1. 「3x²y 与 −5x²y 为什么是同类项？」期望：字母相同、指数相同，系数不同不影响。
  2. 「2πr 与 3r 是同类项吗？」期望：是，π 是数，字母只有 r。
  3. 「合并时字母和指数动不动？」期望：不动，只把系数相加。
  4. 「−(a−b) 为什么等于 −a+b？」期望：−1 乘两项，第二项负负得正。
  5. 「为什么先化简再求值？」期望：项数变少，计算量小，出错少。

3 个预设场景

标准例：从 72×2 与 72a 的类比开始；易错例：直接看 −3(1−2y)；挑战例：跳到检测题。

常见学生反应

  1. 「同类项看系数。」→ 用 3x²y 与 −5x²y、2ab 与 2abc 对比，明确只看字母部分。
  2. 「−(a−b) 就是每一项都变号。」→ 追一句「为什么」，让他说 −1 乘 −b 得 +b。
  3. 「−3(1−2y) = −3−2y。」→ 让他把 −3 分别写在 1 和 −2y 下面，逐个乘。
  4. 「2a+3b 写成 5ab。」→ 用 a=1、b=2 代值，2+6=8，而 5ab=10，立刻看出不对。

与板书、题单的衔接

板书三行：同类项（两相同、两无关）；合并（系数加、字母指数不变）；去括号（括号外因数乘每一项）。题单 8 题：2 题判断同类项、2 题合并、2 题去括号、2 题化简求值。批改只看「有没有乘到每一项」。

课后 1 题

化简 (5a+4c+7b)+(5c−3b−6a)，并说出每一步用了什么依据。答案：−a+4b+9c。

长春落点
