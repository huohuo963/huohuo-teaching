有理数的减法 减去一个数，等于加上它的相反数

上下两条路径，一条是 a − b，一条是 a + (−b)。终点一定重合——这就是减法的转化。

01

两条路，同一个终点

红线是「a 减去 b」，黄线是「a 加上 b 的相反数」。拖动 a、b 看它们始终重合。

上面虚线：a + (−b)；下面实线：a − b。两条箭头终点重合。

转化式
8 − (−3)
变成加法
8 + 3
结果
11
减去一个数，等于加上这个数的相反数：a − b = a + (−b)。转化时两件事一起变：减号变加号，减数变相反数。

例：15 − (−3) = 15 + 3 = 18；3 − 5 = 3 + (−5) = −2；0 − (−7) = 0 + 7 = 7。

03

教材例题

每一步都把「转化」写出来，别跳步。

例：计算 15 − (−3)。

15 − (−3) = 15 + 3 = 18。减号变加号，−3 变 +3。

例：计算 0 − (−7)。

0 − (−7) = 0 + 7 = 7。注意不是 0，也不是 −7。

例：计算 (−5) − (−8)。

(−5) − (−8) = (−5) + 8 = 3。转化为加法后，异号相加，8 的绝对值大，取正。

例：计算 3 − 5。

3 − 5 = 3 + (−5) = −2。小数减大数，结果是负的。

阅读与思考：我国古代正负数加减法则

《九章算术》里已有「正负术」：同名相除、异名相益等说法，用今天的记号就是同号相加、异号相减。我们现在的法则，古人两千年前就在用。

04

四个常见错误

错误 01

「只把减号改成加号。」

减数也要变相反数。3 − (−5) 要写成 3 + 5，不是 3 − 5，也不是 3 + (−5)。

错误 02

「3 − 5 = 2。」

小数减大数得负：3 − 5 = 3 + (−5) = −2。

错误 03

「0 − (−7) = 0。」

0 减负数等于加上正数：0 + 7 = 7。

错误 04

「减法不能转化，直接大减小。」

减法必须先转成加法，再用加法法则；不能拿两个数的绝对值直接相减。

教师模式 · 2.1.2

本节目标

学生能说清「减号变加号、减数变相反数」，并把减法稳定转化为加法。

3 分钟开场

「15 − (−3)，有人得 12，有人得 18。差别在哪？就在那个『减负数』上。今天不背，我们画两条路：一条直接减，一条先变成加相反数，看它们是不是停在同一个地方。」

5 个追问

  1. 「减去一个数，等于加上什么？」期望：这个数的相反数。
  2. 「3 − 5 等于几？」期望：−2。
  3. 「15 − (−3) 等于几？」期望：18。
  4. 「0 − (−7) 等于几？」期望：7。
  5. 「转化时要改几处？」期望：两处，减号变加号、减数变相反数。

常见反应

① 只改减号——用双路径图指出第二条箭头的方向。
② 小数减大数得正——把 a 调小、b 调大。
③ 0 减负数得 0——用「0 − (−7)」预设。
