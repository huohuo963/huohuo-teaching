第二章 · 2.2 有理数的乘法与除法 · 2.2.2

有理数的除法 除以一个数，等于乘它的倒数

算理可视化 0 不能作除数 5 题当堂检测 单文件 · 断网可用

把「÷ b」翻成「× 1/b」，符号和数字都照乘法走。先把 b = 0 这条红线看清楚。

01

除法转乘法：翻的是除数

a ÷ b 与 a × (1/b) 是同一件事；箭头停在同一处。b 不能是 0。

结果在数轴上的位置；红色箭头方向表示商的正负。

转化式
−12 ÷ 3
变成乘法
−12 × 1/3
商
−4
b = 0 时不能除：除数不能为 0，因为找不到一个数乘 0 等于 a（a ≠ 0）。
除以一个不等于 0 的数，等于乘这个数的倒数：a ÷ b = a × 1/b（b ≠ 0）。两数相除，同号得正，异号得负，并把绝对值相除。

0 除以任何不等于 0 的数都得 0；但 0 不能作除数，0 ÷ 0 也没有意义。

02

法则拆成三句

，等于乘这个数的倒数； 两数相除，； 。

点一句，看它和乘法怎么接上。

03

教材例题

先把除法写成乘法，再定符号。

例：计算 (−36) ÷ 9。

(−36) ÷ 9 = (−36) × 1/9 = −4。异号得负，36 ÷ 9 = 4。

例：计算 (−12/25) ÷ (−3/5)。

(−12/25) ÷ (−3/5) = (−12/25) × (−5/3) = 4/5。同号得正，再约分。

例：计算 0 ÷ (−2026)。

0。0 除以任何不等于 0 的数都得 0。

回扣 1.2.1：学完除法，有理数可以写成什么形式？

有理数可以写成 p/q（p、q 是整数，q ≠ 0）的形式。这正是第一章「可以写成分数形式」的完善说法。

04

四个常见错误

错误 01

「0 可以作除数。」

除数不能为 0；0 ÷ 0 也没有意义。被除数可以是 0。

错误 02

「除以 b 就是乘 b。」

要乘倒数 1/b，不是 b。÷ 3 是 × 1/3。

错误 03

「商的符号跟被除数。」

看两个数的符号：同号得正，异号得负，和被除数谁在前无关。

错误 04

「倒数就是相反数。」

倒数看积为 1（3 与 1/3）；相反数看和为 0（3 与 −3）。

本节目标

学生能把除法稳定转化为乘法，会用符号法则，并记住 0 不能作除数。

3 分钟开场

「(−36) ÷ 9，和 (−36) × 1/9，是不是一回事？如果是，除法就不用另学一套法则了。今天只做一件事：把『除以』翻成『乘倒数』。」

5 个追问

  1. 「除以 3 等于乘几？」期望：1/3。
  2. 「(−36) ÷ 9 等于几？」期望：−4。
  3. 「0 ÷ (−2026) 等于几？」期望：0。
  4. 「0 能作除数吗？」期望：不能。
  5. 「(−12/25) ÷ (−3/5) 的符号？」期望：正。

常见反应

① 除以 b 乘 b——用转化式强调倒数。
② 0 作除数——点「试试 b = 0」看提示。
③ 符号跟被除数——回到「同号/异号」。
