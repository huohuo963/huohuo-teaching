有理数的加法 两支箭头首尾相接，落点就是和

先猜 a + b 会落在原点的哪一侧，再看箭头走一遍。异号相加，重点看「谁的绝对值大」。

01

在数轴上把加法走出来

第一支箭头走 a，第二支从 a 继续走 b；终点就是 a + b。

箭头向左表示负数，向右表示正数；两支箭头首尾相接。

先猜：按现在的 a、b，a + b 会落在哪里？选一个，再看箭头。

选一个，不判对错；看看箭头再自己判断。

同号相加：取相同的符号，绝对值相加。异号相加：取绝对值较大的那个数的符号，用较大的绝对值减较小的绝对值。

互为相反数的两个数相加得 0；一个数同 0 相加，仍得这个数。

02

法则拆成三句

：符号不变，绝对值相加； ：取绝对值大的加数的符号，用大绝对值减小绝对值； ：仍得这个数。

点一句，看它最容易错在哪一步。

03

教材例题

先定符号，再算绝对值；两步都写出来。

例：计算 (−3) + (−9)。

同号相加：符号取「−」，绝对值 3 + 9 = 12，所以 (−3) + (−9) = −12。

例：计算 (−8) + 0。

任何数同 0 相加仍得这个数，所以 (−8) + 0 = −8。

例：计算 12 + (−8)。

异号相加：|12| = 12，|−8| = 8，12 > 8，符号跟 12 取「+」；12 − 8 = 4。所以 12 + (−8) = 4。

例：计算 (−4.7) + 3.9。

异号相加：|−4.7| = 4.7，|3.9| = 3.9，4.7 > 3.9，符号取「−」；4.7 − 3.9 = 0.8。所以 (−4.7) + 3.9 = −0.8。

例：计算 (−1/2) + 1/2。

互为相反数，和为 0。不要写成 1 或 −1。

04

四个常见错误

错误 01

「异号相加，符号跟第一个数。」

符号跟绝对值较大的那个数，不是跟写在前面的数。(−7) + 4 = −3，不是 +3。

错误 02

「大绝对值减小绝对值，减反了。」

一定用大减小。(−2) + 9：9 − 2 = 7，不是 2 − 9。

错误 03

「互为相反数相加得 2a。」

a + (−a) = 0，不是 2a，也不是 a。

错误 04

「加 0 会改变符号。」

a + 0 = a，符号、数值都不变。

本节目标

学生能借数轴解释加法法则，先定符号、再算绝对值，异号相加不把符号判错。

3 分钟开场

「(−3) + (−4) 好办，两个负数，越加越小。可 12 + (−8) 呢？是 20 还是 4？我们先不背法则，把它放到数轴上走一遍：先走 12，再往回走 8，看看停在哪儿。」

5 个追问

  1. 「同号相加，符号怎么定？」期望：取相同符号。
  2. 「异号相加，符号跟谁？」期望：跟绝对值大的。
  3. 「(−4.7) + 3.9 的符号？」期望：负，因为 4.7 > 3.9。
  4. 「(−1/2) + 1/2 等于几？」期望：0。
  5. 「a + 0 等于几？」期望：a。

常见反应

① 符号跟第一个数——把 a 调小、b 调大验证。
② 大减小减反——让学生先写「谁大」再减。
③ 相反数得 2a——用「相反数」预设。

衔接

模型停在 01 屏；接着板书「一定符号、二算绝对值」，再做 4 道只判符号的口答题。
