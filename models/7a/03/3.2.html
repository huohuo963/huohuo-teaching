01

先看一个会变的式子

学校购排球：每班配 5 个，学校另留 20 个。全校有 n 个班，一共需要 5n+20 个。

5n + 20
15 个班
5 × 15 + 20 = 95n = 15 时，共需 95 个排球

同一个式子，n 不同，算出的结果就不同。n=15 得 95，n=20 得 120。代数式的值由字母所取的值决定。

观察：2x+3 随 x 增大一直变大；x²−1 先变小、后变大，在 x=0 时取到 −1。不是所有代数式都「x 越大值越大」。

04

教材例 1：两个字母的求值

根据 x、y 的值，分别求 2x+3y 的值。注意第 (2) 问的 y 是分数。

(1) 当 x=15，y=12 时，求 2x+3y

先写条件，再抄式子，然后代值，最后计算。

当 x=15，y=12 时，
2x+3y
= 2×15 + 3×12
= 30 + 36
= 66
(2) 当 x=1，y=1/2 时，求 2x+3y

分数代入要加括号：3×(1/2)，不能写成 3×1/2 后把分子分母拆开乱算。

当 x=1，y=1/2 时，
2x+3y
= 2×1 + 3×(1/2)
= 2 + 3/2
= 7/2（也可写 3.5）

提醒：结果写 7/2 或 3.5 都可以；但过程里「3×(1/2)」的括号不能省，它提醒你 1/2 是一个整体。

05

教材例 2：负数代入，最容易错

求 a²−b/4 的值。先看一份「小明的解法」，找一找错在哪一步。

小明的解法（当 a=−3，b=2 时）

a² − b/4
= −3² − 2/4
= −9 − 0.5
= −9.5

错在第 2 行：−3² 表示「3 的平方的相反数」，等于 −9；而 a² 里的 a 是 −3，代入应写 (−3)²，等于 9。负数代入平方，必须加括号。

正确过程：当 a=−3，b=2 时，a²−b/4 = (−3)² − 2/4 = 9 − 1/2 = 17/2（即 8.5）。

07

规律：火柴棒搭三角形

按图这样连排搭下去：第 1 个三角形用 3 根，以后每多搭一个，只多用 2 根。拖 n 看要多少根。

n = 5，需要 2×5+1 = 11 根每多一个三角形，多 2 根
5 个
n123456
火柴棒35791113

怎么得到 2n+1：第 1 个用 3 根；后面 n−1 个，每个只用添 2 根。所以总数 = 3 + 2(n−1) = 2n+1。也可以说：n 个三角形各有 3 条边，共 3n 条，其中 n−1 条是共用的，每条被算了两遍，减去 (n−1)，得 3n−(n−1)=2n+1。

规律题的正确用法：先列表看前几个，再猜想含 n 的式子，最后代 n 验证。它是「用字母表示第 n 个」的训练，不是长春卷固定题型。

08

六个常见错误

求值错，多半不是不会算，而是代入这一步没写规范。每条都给出错因。

错误 01

a=−3 代入 a²，写成 −3²

−3² = −9，是「3 的平方的相反数」；a² 应为 (−3)²=9。负数代入平方、乘方，必须加括号。

错误 02

2x 代入 x=3，写成 23

省略的乘号要还原：2x = 2×3 = 6，不是二十三。

错误 03

2x² 代入 x=3，算成 (2×3)²

乘方先算：2x² = 2×3² = 18；(2×3)² = 36，多乘了一次 2。

错误 04

分数代入不加括号

如 3/(x+1) 中 x=1/2，应写 3/((1/2)+1)=2。不加括号，分母到底是谁就说不清。

错误 05

把「值」写成式子

代数式的值是一个数，不是「2x+3」这样的式子。算完要落成一个数（或一个确定的分数、小数）。

错误 06

由值反推字母，认定只有一个答案

x²=4 时，x 可以是 2，也可以是 −2。值相同，不代表字母只有一种取法。

09

当堂检测：5 题

选中即判对错，下面有解析。做完可重做；不计入任何记录。

1. 当 a=−2 时，代数式 3a+1 的值是（ ）

解析：3a+1 = 3×(−2)+1 = −6+1 = −5。负数代入要加括号。

2. 当 x=1/2，y=−2 时，代数式 2x−y 的值是（ ）

解析：2x−y = 2×(1/2)−(−2) = 1+2 = 3。减去负数等于加正数。

3. 已知 a²+a=3，则 2a²+2a−1 的值是（ ）

解析：整体代入：2a²+2a−1 = 2(a²+a)−1 = 2×3−1 = 5。不需要先求出 a。

4. 按本节图示的方式连排搭 n 个三角形，需要火柴棒（ ）

解析：第 1 个 3 根，以后每多一个添 2 根：3+2(n−1)=2n+1。代 n=2 验证：5 根，正确。

5. 当 x=−3 时，代数式 x²−2x 的值是（ ）

解析：x²−2x = (−3)²−2×(−3) = 9+6 = 15。两处负数代入都要加括号。

小结与中考连接

求值四步：当…时 → 抄式 → 代值加括号 → 按顺序算。字母取值不同，代数式的值一般也不同；值相同，不代表字母只有一种取法。

最容易丢分的地方：负数平方不加括号、省略乘号不还原、分数代入不括起来、算完不落成一个数。

长春真题回看（2025 第 11 题，填空 3 分）：已知 a²+2a=4，则代数式 7−a²−2a 的值为 ____。
解：7−a²−2a = 7−(a²+2a) = 7−4 = 3。这里用的是整体代入：把 a²+2a 看成一个整体，不必先求出 a。

命题落点：长春卷近年在本章通常考 1 道 3 分选填——2023 第 11 题考列代数式，2025 第 11 题考整体代入求值。更常见的是把求值嵌进后续「先化简再求值」和实际应用题里。把四步写规范，比多刷十道题有用。

教师模式 · 3.2

2024 人教版七上第 3 章；核对 2026-11-26。按 T 可随时开关。

本节目标

学生能说出代数式的值的定义，按四步求值；能在负数、分数、乘方代入时加括号；能用列表观察值随字母变化，并用 2n+1 表示火柴棒规律。

3 分钟开场（可直接念）

「同一个式子 5n+20，n=15 时是 95，n=20 时是 120。式子没变，变的是 n。今天我们就学：给字母一个数，怎样把式子的结果算出来，而且写得让人挑不出毛病。」

5 个追问（按顺序）

  1. 「2x 里的乘号去哪了？代 x=3 时怎么写？」期望：省略了，要还原成 2×3。
  2. 「a=−3 时，a² 等于多少？」期望：9；写成 −3² 就错了。
  3. 「y=1/2 代入 3y，括号要不要加？」期望：要，3×(1/2)。
  4. 「2x² 和 (2x)² 一样吗？」期望：不一样，18 与 36。
  5. 「已知 a²+a=3，能不能不求 a 就算 2a²+2a−1？」期望：能，整体代入得 5。

3 个预设场景

标准例：从 5n+20 和四步开始；易错例：直接看负数平方；挑战例：跳到检测题。

常见学生反应

  1. 「直接心算，不写过程。」→ 先要求写「当…时」和代值那一行，过程分就在这里。
  2. 「−3² 和 (−3)² 差不多。」→ 让他在同一题里各算一遍，看到 −9 与 9。
  3. 「值算出来是 2x+3。」→ 强调值是一个数，不是式子。
  4. 「规律题靠猜。」→ 要求列表、代 n=1,2,3 验证，再写含 n 的式子。

与板书、题单的衔接

黑板只留四步和三个括号提醒（负数、分数、乘方）。题单选 6 题：2 题直接求值、2 题负数/分数、1 题整体代入、1 题规律。做完当堂对答案，重点看过程而不是结果。
