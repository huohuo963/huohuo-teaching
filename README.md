# 火火教学 · 初中数学模型

初中数学各节的交互模型站点。每一节一个**单文件 HTML**，可离线运行，部署在 GitHub Pages。

- 线上站点：<https://huohuo963.github.io/huohuo-teaching/>
- 仓库：<https://github.com/huohuo963/huohuo-teaching>（仓库名用英文，避免 Pages 链接变成中文编码串；站点品牌仍为「火火教学」）

## 信息架构

教材按 **2024 新版人教版**，六册 → 章 → 节三级组织，数据全部来自用户提供的逐节目录：

- 六册：七上（第 1–6 章）、七下（7–12）、八上（13–18）、八下（19–24）、九上（25–29）、九下（30–33）
- 共 **33 章**；章下细分到节，包含三级小节，以及「阅读与思考」「实验与探究」「观察与猜想」「信息技术应用」「数学活动、小结、复习题」「综合与实践」「课题学习」等栏目
- 站点是单页应用，左侧是「册（可折叠）→ 章（手风琴展开）→ 节」的目录树；顶部搜索可按节名、章名或节号（如 `7.2.2`）直接定位
- 路由：`#/` 首页 · `#ch=7` 章页 · `#s=7.2.2` 节页 · `#g=7a` 首页定位到某册

每节先占位，不批量生成模型；做好一节就上线一节。

## 目录结构

```
.
├── index.html                 站点骨架（侧栏 + 顶栏搜索 + 主视图）
├── css/style.css              全站样式（暖纸底、赭石点缀）
├── js/
│   ├── curriculum.js          教材目录（册 → 章 → 节，唯一数据源）
│   └── app.js                 目录树、路由、搜索、节页面渲染
├── models/                    各节模型，按「册/两位章号/节号.html」存放
│   ├── 7a/01/1.2.2.html       示例：七上第 1 章 1.2.2 数轴
│   ├── 7b/  七年级下册
│   ├── 8a/  八年级上册
│   ├── 8b/  八年级下册
│   ├── 9a/  九年级上册
│   └── 9b/  九年级下册
├── templates/chapter-template.html   新节模型模板
└── .nojekyll                  跳过 Jekyll 处理
```

## 命名约定

- 册目录：`7a` 七上、`7b` 七下、`8a` 八上、`8b` 八下、`9a` 九上、`9b` 九下
- 模型文件：`models/<册>/<两位章号>/<节号>.html`
  - 例：`models/7b/07/7.2.2.html`（七下第 7 章 7.2.2 平行线判定）
  - 例：`models/8a/16/16.5.1.html`（八上第 16 章 16.5.1 平方差公式）
  - 阅读/探究等栏目用数据里的节 id，如 `models/7a/01/1.2-rd.html`
- 每个模型文件自带样式与脚本，不引用任何外部 CDN 或图片，双击即可离线打开
- 站点统一视觉：纸色 `#f5efe2`、面板 `#fffdf8`、墨色 `#2b2419`、赭石 `#a3541f`，点缀色只用于强调和按钮

## 新增一节模型（三步）

1. 复制 `templates/chapter-template.html` 到 `models/<册>/<两位章号>/<节号>.html`
2. 完成页面，顶部保留返回链接并加 `target="_top"`：
   `../../../index.html#ch=【章号】`
3. 打开 `js/curriculum.js`，找到该节，加上 `ready: true`

刷新站点后，这一节会直接内嵌显示模型，首页与章页的「已上线」计数自动加一；未完成的节显示占位版式和制作说明。

## 本地预览

推荐在项目根目录起一个静态服务（与线上行为一致，iframe 加载不受浏览器本地文件策略影响）：

```powershell
python -m http.server 8080
```

访问 <http://localhost:8080>。直接双击 `index.html` 也能看目录与占位页，但个别浏览器会限制 `file://` 下的 iframe。
